# Andraya — Hand-Drawn Home Portraits

A design mockup for a commission website where customers purchase custom illustrations of their homes — line drawings, shaded artwork, and optional full color.

## Preview locally

```bash
cd web
npm install
npm run dev
```

Open the URL shown in the terminal (typically http://localhost:5173).

## What's included

- **Hero** — Value proposition with sample line drawing
- **How It Works** — 4-step commission flow
- **Styles & Pricing** — Classic Line ($89), Line + Shading ($149), Full Color ($249, optional upgrade)
- **Gallery** — Portfolio grid with style tags
- **Testimonials** — Social proof section
- **Order Form** — Commission request mockup (no backend yet)
- **FAQ** — Common questions

Built with React, TypeScript, Vite, and Tailwind CSS v4.
